01 — Sobre mí

Curiosidad primero, código después.

Empecé en la web porque quería entender cómo funcionaban las cosas que usaba todos los días. Hoy disfruto el proceso de tomar una idea difusa y convertirla en algo que se pueda usar, probar y mejorar.

Me interesa el producto completo: la estructura, el detalle visual, la accesibilidad y el rendimiento. Trabajo con HTML semántico, CSS a mano y JavaScript sin dependencias cuando el proyecto lo permite.

Estoy en búsqueda de mi primera oportunidad profesional, con espacio para aprender rápido y aportar desde el primer día.
